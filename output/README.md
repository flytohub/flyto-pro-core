# Generated Examples

The `example_*.yaml` files are deterministic Factory outputs generated by
`python generate_real.py`. They demonstrate only blueprints published in the
supported `flyto-blueprint` catalog. Regenerate and review them whenever
Factory selection, composition, enrichment, or the Blueprint dependency range
changes.

These are templates, not proof of successful execution. Runtime validation
belongs to Flyto2 Core; `python test_closed_loop.py` exercises that optional
local integration without committing its transient output.
