# Source Map

`flyto_pro_core` is the only distributable Python package in this tree. Its
seven primary areas are `contract`, `agent_runtime`, `cost`, `interfaces`,
`factory`, `core`, and `config`. The package validates, composes, records, and
adapts workflow data; it does not run a hosted service or execute workflows.

Start with [Architecture](../ARCHITECTURE.md), then use the domain guides in
[`docs/`](../docs/README.md) and the generated
[Python API inventory](../docs/reference/python-api.md).
